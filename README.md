# Student Consultation Booking System

## Project Description

The Student Consultation Booking System is a web-based system designed to help students book consultation appointments with lecturers.

The system allows students to view available consultation slots, submit consultation requests, and manage their appointments. Lecturers can manage their availability and approve or reject consultation requests.

## Project Objectives

- To provide an online platform for students to book consultation appointments.
- To help lecturers manage their consultation schedules.
- To prevent overlapping consultation appointments.
- To improve communication between students and lecturers.
